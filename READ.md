# 💔 Broken Heart Snake Game

A classic Snake Game made with Python and Pygame with a dramatic twist.

## 🎮 Features
- Classic Snake game mechanics.
- Custom Game Over screens that trigger heartbreak videos and music upon clicking **Try Again** or **Exit**.
